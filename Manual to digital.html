Project 01

Manual to Digital Migration Plan

Role: Business Analyst

Focus: Requirements and process mapping

Tools: SQL, flowcharts, Excel

This project looks at how a paper-based medical file system can be changed into a digital system. The goal is to reduce missing records, improve access to patient information, and make the process easier for healthcare staff.

What I have done so far

  • Defined the problem with manual medical files.
  • Listed the basic requirements for the new digital system.
  • Planned a current process flow and a future digital process flow.
  • Identified patient data fields that can be collected and stored.

Deliverables

  • Requirements document
  • Process flowchart
  • SQL data collection plan
  • Migration checklist
