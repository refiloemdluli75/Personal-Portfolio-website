Project 03

Food Delivery App Launch Charter

Role: Project Coordinator / BA

Focus: Project planning

Tools: Gantt chart, resource plan

This project is based on a startup that wants to build and launch a food delivery app in three months. The aim is to define the project clearly before development starts.

What I have done so far

  • Defined the project objective and expected launch timeline.
  • Outlined the scope of the food delivery application.
  • Started a project charter with assumptions, constraints, and stakeholders.
  • Planned resources including designer, developers, and tester.

Deliverables

  • Project charter
  • Gantt chart
  • Resource plan
  • Milestone and launch plan
