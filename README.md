# Business Analysis Portfolio Website

This is a personal portfolio website built with HTML, CSS, and JavaScript only.

It is designed by a final-year Diploma in IT student who wants to specialize in Business Analysis and apply for internships, graduate programmes, and entry-level Business Analyst roles. 

Purpose of the Website:

The purpose of this portfolio is to showcase my understanding of Business Analysis concepts, project documentation, problem-solving skills, and ability to present IT-related solutions in a professional way.

Technologies Used:

\- HTML

\- CSS

\- JavaScript 

## Pages included

* index.html \- main portfolio page  
* projects/manual-to-digital.html \- Manual to Digital Migration Plan  
* projects/ecommerce-checkout.html \- E-Commerce Checkout Optimization  
* projects/food-delivery-charter.html \- Food Delivery App Launch Charter  
* projects/server-risk-register.html \- Server Upgrade Risk Register  
* project-files/ \- folders where project evidence and downloadable files can be added

Featured Projects

1.Manual to Digital Migration Plan  
A project focused on moving patient records from a paper-based system to a digital database system.

2.E-Commerce Checkout Optimization  
A business analysis project focused on improving the online checkout process to reduce customer drop-off.

3\. Food Delivery App Launch Charter  
A project charter for launching a food delivery application.

4.Server Upgrade Risk Register  
A risk register identifying possible risks, impacts, and mitigation strategies for a server upgrade project.

Project Goal 

This portfolio is created to demonstrate my readiness for internship and graduate opportunities in Business Analysis by showing practical project work, documentation skills, and understanding of IT business solutions.
